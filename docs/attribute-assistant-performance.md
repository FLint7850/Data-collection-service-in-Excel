# Attribute Assistant: быстрый и восстанавливаемый конвейер

## Что изменилось

- Импорт ссылок выполняется в фоне и сразу создаёт видимую обработку.
- Команда «Обработать автоматически» последовательно запускает доноров,
  ChatGPT только для нерешённых товаров и безопасное принятие результатов с
  высокой уверенностью.
- Состояние массовой операции хранится в `attribute_batch_operations`.
  После перезапуска незавершённая операция становится приостановленной и может
  быть продолжена; отдельно можно повторить только ошибочные товары.
- Операцию можно приостановить между ограниченными сетевыми задачами. Импорт
  ссылок не ставит в очередь сразу весь пакет, поэтому остановка не ждёт
  завершения сотен ещё не начатых запросов.
- Очищенный снимок страницы, время загрузки и SHA-256 сохраняются вместе с
  источником. Повторный анализ не скачивает ту же страницу заново.
- В запрос ChatGPT попадают только нерешённые поля и относящиеся к ним факты.
  Уже подтверждённые значения остаются локальными.
- Скомпилированные индексы одинаковых справочников переиспользуются в процессе,
  а изменение синонима инвалидирует локальный индекс по фактическому содержимому.
- По умолчанию одновременно выполняются два запроса ChatGPT. Значение можно
  изменить через `ATTRIBUTE_CHATGPT_CONCURRENCY` (1–8).
- Docker-контекст исключает локальные зависимости Codex CLI; это уменьшает
  отправляемый при сборке контекст примерно с сотен мегабайт до сотен килобайт.

## Интерфейс проверки

Новая обработка открывается на фильтре «Требуют решения». Доступны переходы к
предыдущему/следующему проблемному товару, «Принять и дальше», отмена последнего
изменения и клавиатурные команды:

- `Alt+↑` / `Alt+↓` — предыдущий / следующий товар;
- `Alt+Enter` — принять первое ожидающее предложение;
- `Alt+Backspace` — отменить последнее изменение.

## Наблюдаемость

Карточка источника показывает длительность подготовки страницы и запроса,
размер запроса/ответа, токены bridge и факт использования сохранённого снимка.
Сырые prompt и HTML в метрики не записываются.

## Обслуживание SQLite

Перед `VACUUM` сервисы, записывающие в БД, нужно остановить и создать резервную
копию SQLite Backup API. После операции обязательны `PRAGMA integrity_check` и
повторный запуск healthcheck. Миграции не удаляют идентификаторы значений
справочника: это сохраняет правила сопоставления и историю решений.
